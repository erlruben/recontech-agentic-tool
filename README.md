# Recontech Agentic Tool

A free Windows desktop app by Recontech that puts your Claude Code terminals side by side and gives them a shared local memory built from your past sessions.

- **Download:** [latest installer](https://github.com/erlruben/recontech-agentic-tool/releases/latest/download/RecontechAgenticTool-Setup.exe) · [all releases](https://github.com/erlruben/recontech-agentic-tool/releases)
- **Website:** https://erlruben.github.io/recontech-agentic-tool/

The installed app updates itself from the releases here. This repository holds only the installers and the website; the source code is private.

Claude and Claude Code are products of Anthropic; this project is independent and not affiliated with Anthropic.
